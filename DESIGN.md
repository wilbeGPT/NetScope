# Design System

## Visual theme

Dark technical research workspace. Midnight-blue neutrals, off-white reading text, an electric-blue interaction color, and semantic teal, amber and red reserved for data state.

## Layout

The app uses a compact top product bar, a methodology navigator and a central reading workspace. The assistant is a collapsible supporting rail. Report figures remain a linear, full-width academic flow.

## Components

- App shell: product context and global actions.
- Investigation library: list, search context and creation action.
- Phase navigation: Reporte académico plus Fases 1 to 5.
- Assistant panel: contextual assistance, collapsible.
- Research figure blocks: existing implementation, intentionally preserved.

## Interaction

Use crisp opacity and transform transitions under 200ms. Pressable controls scale subtly on press. Honor reduced-motion preferences.
